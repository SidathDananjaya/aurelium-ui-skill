# Design system

This file records the design decisions for this project. It is written once and
read by every later session, human or agent, so the product stays coherent
across conversations.

**If you are an agent working on this project: read this file before changing
any interface, and follow it. It outranks your own preference. If you think a
decision here is wrong, say so and explain why, then follow it unless the human
agrees to change it. Update this file when a decision genuinely changes, and
never let it drift out of date with the code.**

## Accessibility commitments

| Item | Target |
|---|---|
| Standard | WCAG 2.2 AA |
| Body text contrast | 4.5:1 minimum |
| Minimum target size | 24 by 24, primaries 44 by 44 |
| Keyboard | Full operation, visible focus, Escape closes overlays |
| Reduced motion | Every state change stays legible |

Verify with:

```
python scripts/contrast.py --tokens [path to tokens.css]
```
