# Aurelium UI

Design and build interfaces that feel expensive, considered, and effortless.

Luxury in software is the absence of friction and the presence of care.

## Status

This skill is under construction. The full router, dials, workflows, and
reference library are being added phase by phase. The sections below mark what
is coming so the structure is stable while the content lands.

## Modes

**Create.** Design and implement a new web app UI with a coherent design
system, from brief to pre-flight.

**Audit and Elevate.** Score an existing UI against a rubric, report findings by
severity, then upgrade it.

## The five qualities, in priority order

1. **Clarity.** The user always knows where they are and what to do next.
2. **Restraint.** Fewer colors, fewer effects, more space, stronger hierarchy.
3. **Precision.** Exact alignment, consistent rhythm, optical corrections,
   tabular figures.
4. **Material quality.** Considered typography, color, surfaces, and depth.
5. **Effortlessness.** Fast, smooth, accessible, forgiving.
